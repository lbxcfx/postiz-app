# 发布验收清单（内容工厂增强版）

本文档用于第三阶段交付后的上线前验收，面向 `WSL Ubuntu + Docker` 联合架构。

> 所有命令必须在 **WSL Ubuntu** 内执行，不在 Windows CMD/PowerShell 中直接执行。

## A. 基础环境

- [ ] 执行 `./scripts/wsl/preflight-check.sh` 通过
- [ ] 执行 `./scripts/wsl/health-check.sh` 通过
- [ ] `.env` 中关键项配置完整：
  - [ ] `DATABASE_URL`
  - [ ] `REDIS_URL`
  - [ ] `TEMPORAL_ADDRESS`
  - [ ] `MEDIACRAWLER_API_URL`
  - [ ] `CHINA_SOCIAL_SERVICE_URL`

## B. 构建与测试

- [ ] `pnpm --filter ./apps/backend run build` 通过
- [ ] `pnpm --filter ./apps/orchestrator run build` 通过
- [ ] `pnpm --filter ./apps/frontend run build` 通过
- [ ] `pnpm exec jest -c apps/backend/jest.config.ts --runTestsByPath apps/backend/src/services/factory/factory.service.spec.ts --runInBand --forceExit` 通过
- [ ] `pnpm exec jest -c apps/orchestrator/jest.config.ts --runTestsByPath apps/orchestrator/src/activities/analysis.service.spec.ts --runTestsByPath apps/orchestrator/src/activities/content-factory.activity.spec.ts --runInBand --forceExit` 通过

## C. 功能验收（工厂控制台）

- [ ] 工作流分页筛选总数与页数一致
- [ ] 批量取消工作流可用
- [ ] 失败重试策略可配置：
  - [ ] `maxRetryCount`
  - [ ] `batchSize`
  - [ ] `cooldownMinutes`
  - [ ] `concurrency`
  - [ ] `force`
- [ ] “预览本次任务”返回命中数与样例任务
- [ ] 冷却窗口触发时返回 `COOLDOWN_ACTIVE` 且前端提示正确
- [ ] 自动重试可执行并写入审计日志

## D. 历史与追溯

- [ ] “最近重试批次”可筛选（operator/skipped/errorCode）
- [ ] 历史摘要统计与列表一致
- [ ] 历史 CSV 导出可用
- [ ] 历史详情可查看（selectedIds/失败明细）
- [ ] 历史批次可复跑：
  - [ ] 按历史参数复跑
  - [ ] 按当前参数复跑

## E. 回归与性能观察

- [ ] 自动重试并发参数对后端无明显抖动（建议从 3/5/8 逐级验证）
- [ ] 数据库与 Redis 无异常告警
- [ ] Temporal workflow 无持续失败堆积

./scripts/wsl/acceptance-check.sh
```

cd /mnt/f/postiz-app

./scripts/wsl/factory-chain-check.sh
```

## H. 工厂联机 E2E（可选，推荐灰度环境）

```bash
cd /mnt/f/postiz-app
chmod +x scripts/wsl/*.sh
export FACTORY_LIVE_E2E=1
export AUTH_TOKEN='<登录后的 auth token>'
# 可选：指定组织
# export SHOWORG='<organization_id>'
# 可选：指定 integration（未设置时自动取 /integrations/list 第一条可用）
# export FACTORY_INTEGRATION_ID='<integration_id>'
# 可选：指定报告目录（默认 reports）
# export FACTORY_E2E_REPORT_DIR='reports'
./scripts/wsl/factory-live-e2e.sh
```

说明：
- 脚本会调用 `/factory/workflows/start` 启动工作流，轮询草稿后自动审批，再校验 `PublishJob` 到 `SCHEDULED/PUBLISHED`。
- 默认使用 `scheduleAt=当前时间+20分钟`，避免在验收时触发立即外部发布。
- 每次执行会生成一份 JSON 报告：`reports/factory-live-e2e-*.json`。
