# 爆款视频分析

## 1. 当前线上实现（本地规则版）

### 1.1 数据来源
- 素材页搜索结果先映射为 `MaterialItem`，包含点赞/收藏/评论/转发/粉丝/发布时间等字段。
- 映射入口：`apps/frontend/src/components/materials/materials.component.tsx` 中 `mapToMaterialItems(...)`。
- 爆款判定结果和素材会写入本地数据集（`localStorage`），详情页读取后本地计算分析层结果。

### 1.2 爆款判定（Viral Score）
- 实现文件：`apps/frontend/src/components/materials/viral-score.ts`
- 公式：
  - `rawScore = (likes/minLikes)*0.5 + (shares/minShares)*0.3 + (comments/minComments)*0.2`
  - `followerMultiplier = clamp(referenceFollowers / followers, 0.1, 5.0)`（followers=0 时按 1.0）
  - `timeMultiplier = clamp(referenceDays / daysSincePublish, 0.1, 5.0)`
  - `finalScore = rawScore * followerMultiplier * timeMultiplier`
  - `isViral = finalScore >= 1.0`
- 默认阈值：
  - `minLikes=1000`
  - `minShares=200`
  - `minComments=10`
  - `referenceFollowers=50000`
  - `referenceDays=30`
- 分级：
  - `viral >= 3.0`
  - `hot >= 1.0`
  - `warm >= 0.5`
  - 其他为 `normal`

### 1.3 素材详情四层分析（本地规则）
- 实现文件：`apps/frontend/src/components/materials/materials-analysis.engine.ts`

#### 解析层（Parse Layer）
- 文本：标题+描述拼接、分词、停用词过滤。
- 互动规模：
  - `interactions = likes + comments*1.4 + shares*1.6 + collects*1.5`
  - `interactionTotal = round(interactions)`
  - `interactionRate = interactions / followers`（followers<=0 则为 `null`）
- 时长估算：
  - `base = hasVideo ? 32 : 18`
  - `textFactor = min(28, round(textLength / 12))`
  - `interactionFactor = min(20, round(log10(max(interactions,10))*6))`
  - `durationSec = clamp(base + textFactor + interactionFactor, 15, 130)`
- 音频/节奏代理特征：
  - `speechRateRaw = tokens/durationSec*4.5` -> 慢/中/快
  - `pauseDensity = clamp(round((标点数/textLength)*1200), 0, 100)`
  - `emotion` 由情绪词命中数与感叹号数量判定（平稳/积极/高唤起）
- 视频代理特征：
  - `subtitleDensity = clamp(round((tokens/durationSec)*18), 8, 100)`
  - `visualHookStrength = clamp(40 + hookHits*12 + (hasVideo?12:0), 0, 100)`
  - `sceneSwitchDensity = clamp(round((hasVideo?48:26)+min(20,标点*2.2)), 0, 100)`

#### 特征层（Feature Layer）
- `hookStrength = clamp(round(32 + hookHits*14 + (timeMultiplier>1?10:0) + (likes>3000?8:0)), 0, 100)`
- `informationDensity = clamp(round(28 + min(32,tokens*0.9) + min(14,标点*1.4) + (comments>200?8:0)), 0, 100)`
- `emotionStrength = clamp(round(24 + emotionHits*14 + (shares>120?10:0) + (感叹号>=2?8:0)), 0, 100)`
- `conversionStrength = clamp(round(22 + ctaHits*16 + (collects>150?10:0) + (comments>120?6:0)), 0, 100)`
- `rhythmControl = clamp(round(30 + (hasVideo?14:8) + (durationSec<=60?12:6) + (speechRate=中?8:快?6:4)), 0, 100)`
- `visualSignal = clamp(round(30 + (hasVideo?18:10) + visualHookStrength*0.35 + sceneSwitchDensity*0.2), 0, 100)`

#### 评分层（Score Layer）
- 维度权重：
  - 开场钩子：0.24
  - 信息密度：0.22
  - 情绪感染：0.18
  - 转化引导：0.18
  - 节奏控制：0.18
- 总分：
  - `overallScore = clamp(round(sum(score_i * weight_i)), 0, 100)`
- 等级：
  - `S >= 82`
  - `A >= 70`
  - `B >= 58`
  - `C < 58`
- 当前页面“模型置信度”本质是数据可用性评分（非 LLM 概率）：
  - `confidence = clamp(round(44 + title?10 + desc?12 + followers>0?10 + contextLen>5?8:4), 40, 98)`

#### 标签层（Tag Layer）
- 行业标签：词典命中（美妆/穿搭/美食/家居/数码/职场/健康/母婴，未命中则综合）
- 风格标签：规则词命中（教程拆解/对比测评/避坑清单/清单种草/故事叙事）
- 高频词：token 频次 Top8
- 特征标签：基于特征分数阈值映射（如强开场、CTA明确、画面信号强等）

### 1.4 高能时间轴（本地规则）
- 固定切分 6 段：`segmentSec = durationSec / 6`
- 每段热度（0-100）：
  - 段1：`35 + hookStrength*0.6`
  - 段2：`20 + hookStrength*0.25 + informationDensity*0.35`
  - 段3：`18 + informationDensity*0.4 + rhythmControl*0.3`
  - 段4：`16 + emotionStrength*0.55 + rhythmControl*0.25`
  - 段5：`20 + informationDensity*0.35 + conversionStrength*0.35`
  - 段6：`15 + conversionStrength*0.6 + emotionStrength*0.2`
- 高能判定：`heat >= 75`
- 页面展示：
  - “高能片段数” = `timeline.filter(isHighEnergy).length`
  - “总热度” = `round(sum(heat) / segmentCount)`

## 2. 千问能力接入现状

项目已存在 Qwen 多模态分析实现（当前主要在 content-factory 流程）：
- 文件：`apps/orchestrator/src/activities/analysis.service.ts`
- 已支持：
  - 视觉分析模型：`QWEN_VL_MODEL`（默认 `qwen-vl-max-latest`）
  - 语音识别模型：`QWEN_ASR_MODEL`（默认 `qwen3-asr-flash`）
  - 语义总结模型：`QWEN_SEMANTIC_MODEL`（默认 `qwen3.5-plus`）
- 鉴权与地址：
  - `QWEN_API_KEY` / `DASHSCOPE_API_KEY`
  - `QWEN_BASE_URL` / `QWEN_API_BASE_URL`
- 失败时有本地 fallback（`local-heuristic`）。

## 3. 目标方案：接入千问用于爆款视频分析

### 3.1 总体策略（推荐“三层分析”）
- `L0 即时规则层`（现有）：搜索结果返回后立即可见，0 额外成本。
- `L1 异步AI标准层`：后台异步触发 Qwen（ASR+VL+Semantic），写回结构化结果。
- `L2 深度复盘层`：用户点击“深度分析”或高价值样本触发更高成本模型与更细粒度切片。

这样可以兼顾首屏速度、成本和分析质量。

### 3.2 技术架构（素材页链路）
1. 搜索任务完成后，后端入队 `material-analysis-job`（按视频素材过滤）。  
2. Job Worker 做媒体预处理：抽帧、音轨提取、时长/码率信息。  
3. 并行调用：
   - `runAsrAnalysis`：得到逐句文本、时间戳、语速、停顿点。
   - `runVisionAnalysis`：得到画面主体、镜头变化、字幕区域、关键视觉事件。
4. 融合层（Feature Fusion）：
   - 将 ASR 时间轴与视觉事件对齐，生成统一 `timelineSegments`。
   - 产出解释型特征（hook/信息密度/情绪/CTA/节奏/视觉信号）。
5. 语义总结层（LLM）：
   - 输入融合特征+关键片段，输出摘要、亮点、可优化建议、标签、脚本改写建议。
6. 存储层：
   - `material_analysis_result`（结构化 JSON + 版本 + modelUsed + confidence + tokenCost + latency）
7. 前端：
   - 默认先展示 L0；若 L1/L2 结果存在则自动覆盖并显示“AI分析版本/时间”。

### 3.3 建议的数据结构（新增）
- `analysisVersion`: `v1-rule` / `v2-qwen-standard` / `v3-qwen-deep`
- `source`: `rule` | `qwen`
- `modelUsed`: `{asr, vision, semantic}`
- `confidence`: `{global, asr, vision, semantic}`
- `timeline`: 每段包含
  - `startSec`, `endSec`, `heat`, `isHighEnergy`
  - `signals`: `{asrKeywords, emotion, sceneChange, subtitleDensity, cta}`
  - `evidence`: 可追溯证据（文本片段、帧描述）
- `summaryLayer`:
  - `oneSentenceSummary`
  - `highlights[]`
  - `optimizationSuggestions[]`
  - `reusableScriptTemplate`

### 3.4 触发时机（重点）
- `T1 搜索结果完成后`：异步批量触发 L1（默认）。
- `T2 用户点击详情页时`：
  - 若无 L1，立即触发该条加急任务并先展示 L0。
  - 前端轮询或 SSE 推送，结果完成后热更新。
- `T3 数据变更时`（点赞/评论/转发/粉丝明显变化）：
  - 超过阈值再重算，避免频繁调用。
- `T4 定时重算`：
  - 每日离峰窗口只重算 TopN 高价值素材（按商业权重+流量增速）。

### 3.5 成本与稳定性控制
- 配额控制：按组织、按天、按任务类型设置 token 与并发上限。
- 分级模型：
  - L1 用性价比模型（ASR flash + 标准VL + 轻语义）
  - L2 才用高成本模型和更密集切片。
- 降级策略：
  - 任一子模型失败，保留成功分支 + 规则补齐；
  - 全部失败回退到 `v1-rule`，界面明确“AI分析暂不可用”。
- 缓存策略：
  - 相同视频内容 hash 命中则直接复用分析结果。

### 3.6 质量评估与验收
- 线上指标：
  - 分析完成率、平均延迟、单条成本、降级率。
- 业务指标：
  - 用户点击“查看分析”后的停留时长、复用率、导出率。
- 结果质量：
  - 抽样人工对比：高能片段命中率、建议可执行性、标签准确率。

## 4. 实施路线图（可直接排期）

### Phase 1（1周）
- 打通素材页 -> 分析任务入队 -> 落库 -> 前端读取。
- 复用现有 `analysis.service.ts`，先做到单条素材 L1 可用。

### Phase 2（1~2周）
- 建立时间轴融合与证据链输出。
- 增加“AI版本标识、模型置信度拆分、失败原因与降级展示”。

### Phase 3（1周）
- 上线重算策略、配额治理、成本看板与质量抽检报表。
- 支持 L2 深度分析按钮（按需触发）。

---

## 5. 结论

- 当前素材详情页分析为本地规则引擎，优势是快、稳、低成本。
- 项目已具备千问多模态基础能力，建议采用“三层分析 + 异步回填 + 按需深度分析”的接入路径：
  - 首屏不受影响；
  - 分析质量显著提升；
  - 成本与稳定性可控；
  - 对业务增长（复盘、选题、脚本复用）有直接价值。
